## Overview

The OCR Tool is a Python-based utility that leverages **Tesseract OCR** to extract text from images. It supports both single and batch processing, includes advanced image preprocessing for improved accuracy, and can output the extracted text in multiple formats including plain text, JSON, CSV, HOCR, PDF, and Microsoft Word (.docx). The tool is designed for users who need to digitize large volumes of scanned documents, medical forms, invoices, or any image-based text.

---

## Features

- **Multiple Input Formats**: Supports PNG, JPG, JPEG, TIFF, BMP, WEBP.
- **Batch Processing**: Process entire folders of images with automatic output naming (input name + extension).
- **Image Preprocessing** (optional):
  - Grayscale conversion
  - Deskewing (rotation correction)
  - Border removal
  - Thresholding (binarization)
  - Noise reduction (median blur)
  - Upscaling (resize for small text)
  - Contrast enhancement
  - Sharpening
- **Output Formats**:
  - `.txt` – plain text with metadata headers
  - `.docx` – formatted Word document
  - `.json` – structured data with metadata
  - `.csv` – summary for batch processing
  - `.hocr` – hOCR with positional data
  - `.pdf` – searchable PDF (text layer)
- **Parallel Processing**: Uses multi‑threading to speed up batch jobs.
- **Confidence Filtering**: Optionally discard low‑confidence words.
- **Debug Mode**: Save preprocessed images for inspection.

## System Requirements

- **Operating System**: Windows 10/11, macOS, or Linux.
- **Python**: 3.8 or higher.
- **RAM**: 4 GB minimum (8 GB recommended for large batches).
- **Disk Space**: ~500 MB for Tesseract and language data.

## Installation

### 1. Install Python Dependencies

Create and activate a virtual environment (recommended):

```bash
python -m venv ocr_venv
# Windows
ocr_venv\Scripts\activate
# macOS/Linux
source ocr_venv/bin/activate
```

Install required packages:

```bash
pip install pytesseract pillow opencv-python numpy python-docx
```

### 2. Install Tesseract OCR Engine

The script requires the **actual Tesseract binary** (not just the Python wrapper).

#### Windows
1. Download the installer from [UB‑Mannheim Tesseract releases](https://github.com/UB-Mannheim/tesseract/releases).
2. Run the installer as Administrator.
3. During installation:
   - Select installation path (default: `C:\Program Files\Tesseract-OCR`).
   - ✅ **Check** *“Add Tesseract to the system PATH”*.
   - ✅ Under *“Additional language data”*, select **English** (and any other languages you need).
4. After installation, verify in a **new** Command Prompt:
   ```cmd
   tesseract --version
   ```

#### macOS
```bash
brew install tesseract
```

#### Linux (Debian/Ubuntu)
```bash
sudo apt update
sudo apt install tesseract-ocr
```

The script already contains the default Tesseract path for Windows. If Tesseract is installed in a different location, update the script line:

```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

## Usage

Run the script from the terminal inside your project folder.

### Command Line Arguments

| Argument | Description |
|----------|-------------|
| `image` (positional) | Single image file path. |
| `-d`, `--directory` | Directory containing images for batch processing. |
| `-o`, `--output` | Output file (single mode) or output directory (batch mode). **Required**. |
| `--format` | Output format: `txt`, `docx`, `json`, `csv`, `hocr`, `pdf`. Default: `txt`. |
| `--preprocess` | Enable image preprocessing (recommended for most images). |
| `--psm` | Page segmentation mode (0–13). Default: `6` (uniform block of text). |
| `--confidence` | Minimum confidence threshold (0–100). Default: `0` (no filter). |
| `--resize` | Upscale image by `--resize-factor` (default 2.0). |
| `--sharpen` | Apply sharpening filter. |
| `--save-debug` | Save preprocessed images for debugging. |
| `--workers` | Number of parallel threads for batch processing. Default: `4`. |
| `--verbose` | Print extracted text to console. |
| (Other options) | `--lang`, `--tesseract-path`, `--tessdata-dir`, `--no-threshold`, `--no-deskew`, `--threshold-value`, `--resize-factor`, `--contrast-enhance` |

### Single Image Processing

```bash
python scripts/ocr_complete.py input/document.jpg -o output/document.docx --format docx --preprocess
```

### Batch Processing (Process All Images in a Folder)

Place your images in `input/` folder, then run:

```bash
python scripts/ocr_complete.py -d input/ -o output/ --format docx --preprocess
```

Each output file will be named after the input image, e.g.:

- `input/IMG_0101.jpg` → `output/IMG_0101.docx`
- `input/scan_001.png` → `output/scan_001.docx`

### Output Formats

#### TXT (plain text)
Includes metadata headers (timestamp, confidence, word count) followed by the extracted text.

#### DOCX (Microsoft Word)
Creates a professionally formatted document with:
- Title “OCR Results”
- Metadata table (source image, date, confidence, word count)
- Extracted text split into paragraphs.

#### JSON
Structured output with fields:
```json
{
  "file": "input/image.jpg",
  "timestamp": "2026-05-13T10:30:00",
  "text": "...",
  "metadata": { "word_count": 120, "avg_confidence": 90.58 }
}
```

#### CSV (batch only)
Generates a summary file `combined_results.csv` with columns: `file`, `word_count`, `avg_confidence`, `text_preview`.

#### HOCR / PDF
For developers who need positional data (hOCR) or searchable PDFs.

## Examples

### Example 1: Basic text extraction from a single image
```bash
python scripts/ocr_complete.py input/invoice.png -o output/invoice.txt
```

### Example 2: High‑quality extraction with full preprocessing
```bash
python scripts/ocr_complete.py input/medical_record.jpeg -o output/medical.docx --format docx --preprocess --psm 6 --sharpen --resize
```

### Example 3: Batch convert 200 images to Word docs
```bash
python scripts/ocr_complete.py -d input/ -o output/ --format docx --preprocess --workers 8
```

### Example 4: Debugging – save preprocessed images
```bash
python scripts/ocr_complete.py input/blurry.jpg -o output/debug.txt --preprocess --save-debug
```
Preprocessed images will be saved as `debug_*.png` in the current folder.

### Example 5: Filter low‑confidence words (threshold 70%)
```bash
python scripts/ocr_complete.py input/noisy.png -o output/filtered.txt --confidence 70
```

## Configuration

### OCR Settings

| Parameter | Default | Description |
|-----------|---------|-------------|
| `--lang` | `eng` | Language(s) for OCR. Use `eng+fra` for multiple. |
| `--psm` | `6` | Page segmentation mode. Common values: `4` (single column), `6` (uniform block), `7` (single line). |
| `--confidence` | `0` | Minimum confidence (0–100). Words below this are omitted. |

### Preprocessing Settings

| Flag | Effect |
|------|--------|
| `--preprocess` | Master switch – enables thresholding, denoise, deskew, contrast, border removal. |
| `--no-threshold` | Disable binarization (keeps grayscale). |
| `--no-deskew` | Disable automatic rotation correction. |
| `--resize` | Upscale image by factor (useful for small text). |
| `--resize-factor` | Scale factor (e.g., 2.0 = double size). |
| `--sharpen` | Apply sharpening kernel. |
| `--threshold-value` | Threshold value for binarization (default 150). |
| `--save-debug` | Save intermediate preprocessed images. |

## Troubleshooting

### Error: `tesseract is not installed or it's not in your PATH`
- **Cause**: Tesseract binary not found.
- **Solution**: Install Tesseract (see [Install Tesseract OCR Engine](#install-tesseract-ocr-engine)) and ensure the path is set correctly in the script.

### Error: `Failed loading language 'eng'`
- **Cause**: Language data (`eng.traineddata`) missing.
- **Solution**: Reinstall Tesseract with English language data, or download the file from [GitHub tessdata](https://github.com/tesseract-ocr/tessdata/blob/main/eng.traineddata) and place it in `C:\Program Files\Tesseract-OCR\tessdata\`.

### Batch mode reports twice as many images as expected
- **Cause**: The script previously counted both lower‑case and upper‑case extensions on Windows (e.g., `.jpg` and `.JPG` for same file).
- **Solution**: The script now uses a set or lower‑case suffix check. Update to the latest version of `find_images()` function.

### Extracted text has poor quality
- **Try**: Enable preprocessing (`--preprocess`), increase resolution (`--resize`), or adjust threshold (`--threshold-value`). Use `--save-debug` to inspect the processed image.

### Memory error when processing large batches
- **Reduce** the number of workers: `--workers 2`.  
- **Process** images in smaller sub‑folders.

### `ModuleNotFoundError: No module named 'docx'`
- **Install** python-docx: `pip install python-docx`

## FAQ

**Q: Can I process PDF files directly?**  
A: No, PDF files are not supported as input. Convert PDF pages to images first (e.g., using `pdf2image` library).

**Q: How do I improve recognition of handwritten text?**  
A: Tesseract is not optimal for handwriting. You may need to train a custom model or use specialised handwriting recognition engines.

**Q: Can I use a different Tesseract language (e.g., French, German)?**  
A: Yes, install the corresponding language data during Tesseract installation, then use `--lang fra` (French) or `--lang deu` (German). For multiple languages: `--lang eng+fra`.

**Q: Why are the output `.docx` files larger than expected?**  
A: The script does not embed images, only text. Large size may be due to complex formatting or metadata. Use `.txt` for minimal size.

**Q: How can I suppress the metadata headers in TXT output?**  
A: Edit `save_txt()` method in the script – remove the lines that write the header.
